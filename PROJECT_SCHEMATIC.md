# caffe-game — Схематика проекта (для аналитика)

> Живой документ. Обновляется куратором после каждой итерации улучшений.
> Игра: **«Междумирье»** — нарративный тайкун-симулятор бариста для **Яндекс Игр** (WebGL, десктоп+мобайл). Unity, плагин YG2.
> Жанр-референс: гибрид «time-management кофейня» + «visual novel». Ядро = приготовить кофе по неявному заказу → раскрыть кусочек сюжета.

---

## 1. Сюжет и структура
- Героиня **Мира** (в enum — Anna) держит кофейню «Междумирье» на границе миров; ищет пропавшего мужа **Кая/Андрея**. Антагонист — **Орден Трёх Кругов** и злодейка **Лира**.
- **40 дней** (`Difficulty.FinalDay = 40`), контент на ~42 дня в `StoryDatabase`. Каждый день = 1+ гость.
- Каждый гость — из своего мира (`CharacterType`, ~30 типов), даёт **реплики приветствия → заказ → (если доволен) сюжетное раскрытие / (если нет) реплики недовольства**.
- Между днями: экран результата дня → опц. **виньетка** (спец-эффект + текст) → **«Сон»** (затемнение + эффект из пула + строка кошмара + **ночной эмбиент** «шёпот призраков») → переход. **Порядок звука/рекламы:** музыка глохнет на ночь, во «Сне» играет ночной эмбиент (`AudioController.PlayNight/StopNight`), он выключается на пробуждении → показывается реклама (`Transition`) → и лишь ПОСЛЕ неё возвращается фоновая музыка нового дня.
- **Цель путешествия:** накопить **10000 монет** (`CoinsUI.JourneyGoal`) к дню 40. Не хватило → `JourneyGate`: начать заново (монеты сохраняются) ИЛИ докупить монеты.
- Финал: Кай спасён, светлая концовка.

## 2. Поток одного дня (`DayController.RunDay`)
Заставка «ДЕНЬ N» → по гостям: `ServeCustomer`:
1. Спавн модели гостя (stickman-префаб), ГГ виден за стойкой.
2. Этап 0: гость идёт к стойке (`ProcessVisitor`).
3. Этап 1: приветственный диалог (`DialogueDisplayer.PlayDialogueLines`). Текст появляется **по словам за ~3 с** (`revealDuration`), 1-й клик — показать всю реплику, 2-й клик — следующая (защита `advanceGuard` от быстрого проскока); сбоку мигает «нажмите для продолжения» (`BlinkText`). Бубнёж SpeechMixer.
4. Полоса удовлетворённости = **запомненное** отношение клиента (память по `CharacterType`, старт 50%).
5. **Готовка** (`CoffeeCraftingSystem`): выбор основы → подтвердить → минигейм машины → топпинги → «Подать».
6. Оценка `EvaluateSatisfaction()` (доля из 4 параметров: основа, температура, объём, топпинг).
7. Кружка передаётся гостю; звёзды 1–3⭐ + празднование.
8. Обновление памяти клиента = среднее(старое, новое).
9. Если клиент недоволен (<0.5) → предложить **Комплимент за 50 монет** (+0.3 настроения).
10. **Оплата** (формула ниже) + списание себестоимости.
11. Реакция гостя (эмоция) + сюжетные/недовольные реплики.
12. Гость уходит. Прогресс сохраняется после КАЖДОГО гостя (`SetCustomerIndex`) — обновление страницы продолжает с места.

День провальный ТОЛЬКО если `_coinsEarnedToday < 0` (в минус) → рестарт дня. Провала «за 3 ошибки» нет.

## 3. Экономика (главный рычаг — деньги)
- **Формула оплаты за напиток** (`DayController` стр. 211-217):
  `payment = round( coinsPerCorrectOrder × payScale(=4) × result × (0.5 + tipMood) × EarlyEase(day) × PriceMultiplier(апгрейд) × combo )`
  - `result` 0..1 — качество напитка.
  - `tipMood = clamp01(память клиента + MoodBonus апгрейда)`.
  - `EarlyEase`: ×1.5 день1 → ×1.0 день6 (мягкий старт).
  - `combo`: серия хороших напитков (≥0.6), +0.15/уровень, макс 5 → до ×1.75.
- **Себестоимость:** основа 8 монет, топпинг 3. `_coinsEarnedToday += payment - drinkCost`.
- **Стартовый капитал:** 100 монет.
- **Апгрейды** (`UpgradeShopUI`, макс ур.3): Beans (+12%/ур к оплате, цена 300×ур), Machine (+допуск 0.04/ур, 250×ур), Loyalty (+чаевые 0.06/ур, 200×ур).
- **Сложность** (`Difficulty`): допуск машины 0.22→0.10 к финалу.

## 4. Монетизация (Яндекс)
- **Interstitial (межстраничная):** на каждом переходе между днями (`Transition`).
- **Rewarded (за награду):**
  - «Подсказка» — точный заказ, кнопка **«Уточнить заказ 📺» доступна ВСЕГДА** (добровольно), пульс-подсветка после 2 провалов подряд (`_adHintButton` → `RewardedAdvShow("hint")`). [итер.1]
  - «Нет денег» панель — реклама за монеты (`AdForCoins`, `_noMoneyPanel`).
  - JourneyGate — докупить монеты.
  - **Экран результата дня** (`DayResultUI`): rewarded «Удвоить выручку дня» (id `day_double`, при earned>0) + «Сохранить серию комбо» (id `combo_save`, при серии ≥3 → перенос на завтра) [итер.2].
- **Daily bonus** (`DailyBonusUI`): вход раз в день, растёт со стриком (base + step×(streak-1), капом `maxReward`).
- **Лидерборд** «coins» по общему балансу.
- Звук и геймплей ставятся на паузу на время рекламы и при потере фокуса окна.

## 5. Загадка заказа (ядро вовлечения)
- Игрок видит НЕ точный заказ, а **расплывчатый намёк** (`VagueHint`): «Хочется <основа>, <тёплого>, <в самый раз>…». Точный — только за рекламу-подсказку.
- Соответствие заказа: `type→основа (index%N)`, `sweet→температура` (0.2/0.45/0.65/0.9), `volume→объём` (0.25/0.55/0.85), `topping`.
- **Топпинги (батч рефакторинга):** enum `Topping` = реальные предметы-модели с полки `ShelfItems` (BellPepper, BundtCake, Cookies, Salami, Salmon, Wasabi, Lollipop, Tomato, Pretzel). Билдер (`MakeToppingItems`/`ToppingByName`) сопоставляет топпинг по **имени дочернего объекта**, а не по индексу → визуальная модель = enum = упоминание в реплике совпадают. Реплики гостей переписаны под полочные топпинги (кекс/леденец/печенье; шутка «без васаби»).
- ⚠️ Примечание: `sweet` маппится на ТЕМПЕРАТУРУ машины (не на сахар) — историческое упрощение.

## 6. Минигейм машины (`MachineMinigame`)
Две вертикальные шкалы по очереди (температура, затем объём): бегунок пинг-понгом (`_speed=0.8`), клик фиксирует уровень. Допуск = `Difficulty.Tolerance(day) + апгрейд`. Попал в оба → «В точку!».

## 8. Известные ограничения / зацепки для улучшений
- Нет прямой продажи мягкой валюты пакетами (только rewarded за монеты).
- Один гость на день часто → короткая петля; нет «наплыва»/очереди на скорость.
- Нет ежедневных целей/квестов кроме сюжета; нет коллекций/журнала персонажей.
- `sweet→температура` — неинтуитивно, но менять данные дорого.
- Комбо сбрасывается каждый день; нет «мета-прогрессии» украшения кофейни (визуал апгрейдов).
- ~~Реклама-подсказка только после 2 провалов~~ → [итер.1] теперь добровольна всегда. Всё ещё мало ДРУГИХ rewarded «по желанию» (нет удвоения выручки/сохранения комбо на экране результата).

Положил → ×1.08 к оплате и +0.03 симпатии; проигнорировал явную просьбу → −0.02 симпатии. Связывает журнал с экономикой (второй контур ценности лояльности), поднимает средний чек у ядра. (1) Loss-aversion: при стрике входа ≥3 строка «Стрик N дней 🔥 загляни завтра — иначе сгорит!» (`_streakWarningText`, опц.). (2) Пульс-дожим кнопки «Удвоить выручку» (мягкая пульсация, `unscaledDeltaTime`, стоп при клике/закрытии). Кнопка уже показывает конкретную сумму `+N`. Эффект: рост CTR rewarded «Удвоить» + D1/D2 retention через напоминание о стрике. Без новой сборки UI (правка существующего экрана).

- **Итерация 10 — «Особый гость / Знак дня» ✅** (`DayController.cs`, `CoffeeCraftingSystem.cs`, `GameManager.cs`). Каждый 8-й день (8/16/24/32/40) — особый: ставка ×1.3 (`_specialDayMult`), допуск у́же на −0.02 (`SetExtraTolerance`), анонс в начале дня + тизер «кто-то особенный» накануне в «Сне». Создаёт ритмичные пики вовлечения (якоря-ожидания D8→D40), снижает провал середины. `DayController.IsSpecialDay(day)` — общий хелпер. Баланс: ставку держим ×1.3 (не ×1.4), чтобы стэк с «Удвоить» не ломал темп цели; провал по-прежнему не наказывает сверх обычного.

1. **Показ диалога по словам** (`DialogueDisplayer`): вместо посимвольной «печатной машинки» реплика раскрывается по словам за ~3 с (`revealDuration`). 1-й клик — показать всю реплику, 2-й — следующая; `advanceGuard` (~0.35 с) не даёт быстрым кликом проскочить диалог целиком.
2. **Мигающий хинт «нажмите для продолжения»** (`BlinkText`) вместо статичного «далее ▸». Локализован (ru/en).
3. **Вариативность «Заказа дня» до 10 типов** (`DailyChallenge`): + ServeDrinks, StarCollector, HighSatisfaction, TwoStarsPlus, BigEarnings (seed = день, синхронно у всех).
4. **Реструктуризация топпингов** (`GameEnums`, `CoffeeCraftingSystem`, билдер): enum = предметы полки `ShelfItems`, сопоставление по имени объекта; реплики/подсказки приведены в соответствие (см. раздел 5).
5. **Порядок перехода: сначала реклама, потом музыка** (`GameManager`): `ResumeMusic` перенесён на после `Transition` (см. раздел 1).
6. **Обучение (день 1): скрыты все кнопки HUD, кроме настроек** (`TutorialController.HideHudButtons/RestoreHudButtons` — прячет `BtnJournal`, `BtnHint`, возвращает после обучения).
7. **Ночной звук** «шёпот призраков» (`Assets/Audio/night_ambience.mp3` → `AudioController._nightAmbience`, отдельный зацикленный источник): вкл. с началом «Сна», выкл. до рекламы.
8. **Чистка неподдерживаемых символов** в подписях/сообщениях: шрифт Nunito не содержит ✓ ☕ ✨ 🔥 📺 ⭐ ★ ☆ — все удалены из UI-строк кода (звёзды в журнале → «N / 3»), чтобы не было «квадратиков».
9. **Цветные иконки HUD** из `Mini UI/Icons` (Settings/Book/Blue Energy) вместо линейных из `UI Icons`; иконки не тонируются (`Color.white`).
10. **Схематика обновлена** (этот файл + `ARCHITECTURE_MAP.md`).

> ⚠️ После правок кода нажать **Tools → CoffeGame → Build Scene Systems + UI** в Unity: пересоберёт HUD (цветные иконки, мигающий хинт), привяжет `_nightAmbience` и топпинги по именам полки. Импорт `night_ambience.mp3` произойдёт при открытии редактора.

- **D — Достижения (`Core/Achievements.cs`).** 10 майлстоунов (знакомства/дни/богатство/рекорд endless) → **кристаллы** (главный не-платный источник премиум-валюты). Оценка в конце дня по данным сейва, суммарный поп-ап, метрика `achievement`. _Осталось:_ визуальная кастомизация (аватары `Mini UI/Avatars`, темы `9 Splice Panels`) — поля сейва `avatarId/themeId/ownedCustomizations` готовы, нужен экран выбора + применение (билдер/арт).
- **G — Перф/загрузка WebGL (ручное, в Unity).** См. чек-лист ниже.

### ⚠️ Что сделать в Unity (Батч 12)
1. Открыть проект → сгенерируются `.meta` новых скриптов (`ProgressionManager`, `Achievements`, `LootSystem`, `RewardPopupUI`, `CurrencyHudUI`).
2. **Build Intro (SampleScene)** — пересобрать интро (появится кнопка «Пропустить», привяжется `_skipButton`). Открыть SampleScene → `Tools → CoffeGame → Build Intro`.
3. **G (загрузка/перф):** включить сжатие текстур `Mini UI` (ASTC/DXT) + собрать **SpriteAtlas** по используемым иконкам; удалить неиспользуемые темы/варианты `Mini UI` и не-`_Mobile` префабы `Polygonal Particles`; Build Settings — IL2CPP stripping High, Brotli, exceptions=Explicitly Thrown Only; аудио Load Type (SFX=Decompress, музыка/эмбиент=Streaming). Замерить время до интерактива до/после.
4. _Полировка (опц.):_ магазин кристаллов (кнопки `BuyGems`), экран кастомизации (аватар/тема), 7-дневный календарь/оффер, привязка иконок Mini UI к валютному HUD/лут-попапу.
